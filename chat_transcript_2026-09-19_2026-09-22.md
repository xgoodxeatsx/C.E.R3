## Part 2 — What is Claude Code and how do I install it?

**User:** Whats claude code beta and how do i install and use it?

**Assistant:** Explained that Claude Code is Anthropic's agentic coding tool — reads a codebase, edits files, runs commands, and can commit/open PRs from natural-language instructions. Requires a Pro/Max/Team/Enterprise/Console account (not the free plan). Gave install options:

- **Terminal (recommended, auto-updates):**
  - macOS/Linux/WSL: `curl -fsSL https://claude.ai/install.sh | bash`
  - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
- **Homebrew:** `brew install --cask claude-code`
- **WinGet:** `winget install Anthropic.ClaudeCode`
- **npm:** `npm install -g @anthropic-ai/claude-code` (needs Node 22+)
- Also available as a Desktop app (macOS/Windows), a VS Code/JetBrains extension, or the browser version at claude.ai/code.

Basic usage: `cd your-project && claude` opens an interactive session; log in via the browser prompt on first run, then describe tasks in plain language. Non-interactive piping also works: `claude -p "..." < input`.

Sources cited: [Claude Code Overview](https://code.claude.com/docs/en/overview), [Claude Code Setup](https://code.claude.com/docs/en/setup).

**User:** Which one of these lets me code directly in the Claude interface?

**Assistant:** The browser version at **claude.ai/code** runs directly inside the Claude interface itself — no download or terminal needed; pick/connect a repo and go (also available on the Claude mobile app). The Desktop app is the next closest thing (a dedicated "Code" tab inside Anthropic's own Claude app). The terminal/npm/Homebrew/WinGet routes are all the CLI, run from your own terminal, separate from any Claude interface.
