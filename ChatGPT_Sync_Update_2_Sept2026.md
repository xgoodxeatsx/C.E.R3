1\. Ball System — Major Architecture Completed

The full Modular Ball Workshop architecture is now locked: Ball
Shell/Base → Identity/Lid (the ball's native type + innate effect, the
anchor other components modify rather than replace) → Core (capture
strength) → Attunement Core (established Affinity) → Anomaly Core
(non-standard phenomena, sibling to Attunement not a power tier above
it) → Treatment (special function) → Calibration (optional — activates
dormant modifications, never gates base function) → Master Core
(replaces the Nether Star in the existing Modular Ball mod's Master Ball
recipe, combinable with any other component set).

- Ball assembly is ONE Workshop operation regardless of component count
  — explicit anti-AllTheMons design constraint. Component preparation
  can be its own separate gameplay system; assembly itself never becomes
  a multi-station chore.

- Ball Reverse Engineering locked as a world-discovery mechanic: balls
  must be physically found and analyzed (progressively,
  non-destructively) before their architecture becomes reproducible.
  Ties ball acquisition to varied sources and a trackable Field Guide
  Ball Archive.

- Master Ball confirmed as the umbrella system's Masterwork tier —
  literally built from a sample of every other ball technology, made
  concrete by the Master Core component.

- The ER Ball (Eeveelutional Resonance Ball) supersedes an earlier GS
  Ball reinterpretation idea that was proposed but never actually
  locked. Origin: born from Eeveelutional Resonance research needing to
  measure rather than merely capture Resonance. Evolves Prototype → ER
  Ball → Mk. II/Resonance Ball, giving the Resonance Ball name a genuine
  historical origin and fulfilling the Ritual Legendary-eligibility
  path's need for a physical worked example.

- Ender Dragon Titan gets a dual pathway: catchable through an ordinary
  encounter with no Titan fight required, OR fought as a Titan with
  victory unlocking an evolution/Mega-Evolution path into Chaos Guardian
  specifically. The narrative payoff (years of vanilla rivalry becoming
  an ally) is the explicit point, not incidental.

- 🔵 Draconic Evolution's Chaos Shards and its Ender Dragon/Chaos
  Guardian pairing logged as a brainstorm-stage Titan/Corruption
  integration — not locked, explicitly flagged as spur-of-the-moment.

- A large Ball Fusion/Discovery combination board (50+ specific
  Identity+Attunement+Treatment pairings, e.g. Occult/Eclipse from
  Dusk+Moon+Ghost+Dark) was generated but deliberately NOT transcribed
  into the archive in full — only its governing structural principles
  are locked: most combinations should be Workshop DISCOVERIES rather
  than pre-listed items; six reaction-outcome categories
  (Compatible/Synergistic/Unstable/Contradictory/Anomalous/Transformative);
  trackable ball genealogy; factions reframed as teaching Treatments
  (schools) rather than gatekeeping named balls.

2\. Affinity System — Foundational Architecture Locked

The single most important resolution this batch: Affinity uses the 18
Pokemon types as VOCABULARY, never as an actual hack into a Pokemon's
real types\[\] array. Type describes what a Pokemon IS; Affinity
describes what energy it resonates with. These usually coincide
(Moltres: Fire/Flying type AND Fire Affinity, being literally fire made
manifest) but are structurally separate systems.

- Hidden Resonance (the latent/third-affinity layer) is planned to reuse
  Cobblemon's own existing Hidden Power infrastructure — verified real:
  the battle-calculation layer already computes an IV-derived hidden
  type; only a 2024 display bug (always showing Water) was fixed. Build
  priority: repurpose this before building anything custom.

- Normal-as-fallback locked: a Pokemon's TRUE Affinity exists in world
  data regardless of player knowledge, but affinity-aware systems return
  Normal until the world's research state has discovered that Affinity —
  a world-level 'Known Affinities' ledger, not a per-Pokemon unlock.
  E.g. Charmander presents as Normal-type/Normal-affinity in all
  Affinity systems until Fire is formally discovered.

- Environmental Affinity Pressure formalizes the existing Type Affinity
  Modifier into a full ecological rule: biomes have relative Affinity
  pressure profiles (not hard lookup tables), modified dynamically by
  time/weather/season, with Local Affinity Pockets (an oasis in a
  desert) able to violate the surrounding biome's profile at small
  scale. Governing rule: environment determines prevalence, never
  absolute existence.

- Tech-Mod Repurposing Methodology (brainstorm-stage, principle only —
  no specific machine assignment locked): ask what existing Minecraft
  mechanic can represent an Affinity/Resonance/research concept, sorted
  into four action categories (Processing/Affinity/Pokemon
  biology/Research), rather than which mod to install. Illustrative
  Ender IO + Actually Additions pipeline discussed: SAG Mill extraction
  → Vat refinement → Empowerer infusion → Alloy Smelter synthesis.

- Liquid Source locked: a blank, unaffiliated carrier fluid that gets
  imprinted with a specific Affinity via recipe (Affinity Shards +
  Liquid Source → Liquid \[Affinity\]), giving the existing Liquid
  Affinity concept an actual named origin material.

3\. Fusion Ownership Resolution (major architecture)

Resolves whether Fusion research could invalidate the Synthesis Chamber.
Answer: research determines theoretical possibility; the Chamber
determines practical stabilization; capture alone establishes ownership.
'Research can discover a Pokemon. Synthesis can manifest a Pokemon.
Capture establishes ownership.'

- Original source Pokemon are NEVER consumed. Three escalating
  material-input tiers: (1) Biological Template — a non-destructively
  submitted duplicate specimen; (2) Resonance Template — Affinity
  materials substituting once a species' signature is mapped; (3)
  Synthetic Template — full construction from discovered materials once
  the organism's Resonance structure is fully understood, with no living
  specimen required at all.

- Successful synthesis produces a WILD encounter, not an owned Pokemon —
  mirrors the Titan two-stage weight (manifestation, then capture, as
  separate meaningful moments).

- Failure is genuinely safe: only spent materials/templates are lost,
  never the source Pokemon. Failure outcomes tie into the existing
  Fractured/Shadow categories rather than being a separate fail-state,
  giving Fusion/Fractured/Shadow a shared origin mechanism.

- 🔵 Not locked: reaching a research state sophisticated enough to
  synthesize a species never personally caught, framed as an advanced
  achievement (naturalist → researcher → synthesist).

4\. Discovery Before Ecology & Research Progression

New governing principle resolving how uncatchable/undiscovered
categories (Shadow, Fractured, Fusion, Fakemon) appear in the world at
all without contradicting the existing 'nothing special spawns before
it's earned' rule: undiscovered phenomena don't participate in ordinary
wild spawning until discovered. Rare, uncatchable Anomaly Encounters
(gated behind research-tier milestones so the mechanic can't be missed
for 200 hours OR spoiled at hour 2) provide first contact instead.
Different phenomena use different first-contact mechanisms rather than
one universal event.

- Research Tier Progression: a hidden advancement branch (Observer →
  Surveyor → Researcher → Specialist → Master, names not fully locked),
  invisible until the player's first legitimate research action. Six
  research categories including Chain Research (uninterrupted
  same-species streaks, escalating length/strictness by tier). Master
  unlocks specialized branches (Ecology/Anomalies/Taxonomy) rather than
  being the endpoint — that's where Shadow/Fractured/Fusion/Fakemon
  research genuinely lives.

- Research-to-Quest Bridge: research milestone → hidden Minecraft
  advancement (sidesteps needing a custom CriterionTrigger) → FTB
  Quests' native Advancement task → quest progresses. Avoids hundreds of
  near-identical quests; research data stays the sole source of truth.

- Note: Cobblemon Unchained (a real, current addon, 2.6M+ downloads) has
  a near-identical 'consecutive same-species streak' mechanic already.
  Flagged as a genuine redundancy risk if installed alongside Chain
  Research — recommend NOT running both, though Unchained's specific
  trigger granularity (spawn/fish/hatch/fossil/capture/snack,
  independently configurable) is worth studying when Chain Research gets
  its dedicated session.

5\. Research System Charter — Four Systems, One Job Each

Resolves a genuine four-way overlap (Snap, Research Tasks, a hoped-for
Field Journal, FTB Quests all claiming 'research'):

- Cobblemon Snap owns photographic/observational research (encounter,
  photograph, pose, activity, habitat, Snapdex progression).

- Cobblemon Research Tasks owns active/interactive research (catching,
  battling, breeding, evolving, item/move use).

- The Field Journal (custom, built atop both) owns the narrative layer
  (player notes, favorite photos, discovered lore, world/biome context).

- FTB Quests owns the campaign/expedition layer (multi-step story
  content not tied to a single species).

- The already-locked Field Guide UI becomes the single front-end window
  into all four rather than an implementation of any of them itself.

- Two-camera resolution: Cobblemon Snap's camera is the field-research
  instrument; Exposure is the personal/artistic instrument (scenery,
  printable photos, no research scoring). An earlier 'generic handheld
  camera' placeholder is retired as redundant now that Snap's actual
  camera covers that role.

- 🟡 Open, flagged as a genuine unknown rather than assumed either way:
  whether Snap's shiny-tracking is a generic aspect tracker (in which
  case Shadow/Fractured/Fusion tabs might work natively) or hardcoded to
  the one vanilla flag (in which case that tracking needs to be built in
  the Field Journal layer instead).

6\. Progression Backbone Unification

By this point three systems could each independently gate what a player
is allowed to do: ProgressiveStages (stages/flags), RCT's trainer level
caps (tied to key-trainer defeats), and the new Route Mode concept.
Locked resolution: ProgressiveStages is the single source of truth for
'what has this player unlocked.' RCT level-cap triggers and any custom
Route Mode gate write TO ProgressiveStages flags on completion rather
than keeping independent state.

- Route Mode: confirmed via fresh research that a real 'Routes' mod
  exists (road-generation only, not progression-gating) and Cobblemon
  Nuzlocke Mode is a real precedent for the toggle UX, but NO pre-made
  mod does sequential route-by-route gating. Proposed as a small custom
  build: Routes supplies the physical road geography for free; a custom
  opt-in toggle (styled after Nuzlocke Mode's own command pattern, off
  by default, per-player, saved) rides on ProgressiveStages + RCT's
  key-trainer defeats. A player who never touches the toggle plays
  completely free-roam exactly as today.

7\. World Architecture Resolutions

- Aero Islands confirmed as a vertical Overworld layer (ground level →
  Aero sky layer, Flying/Dragon-leaning ecology) rather than replacing
  worldgen — technical integration (it defaults to replacing generation
  entirely) still needs real testing, not just installing the jar.

- Yatters Biospheres reframed as Lost/Corrupted Biomes: ecosystems that
  became unstable and were quarantined into dimensional biospheres
  rather than naturally occurring. Corruption exists on a spectrum
  (Healthy → Tainted → Corrupted → Lost); research can eventually Purify
  (restore to Overworld), Stabilize (keep isolated), or Harness (control
  the corruption for dangerous new materials/Pokemon).

- Biosphere access split into primary (Threshold Anchor, built via
  Affinity research at a detected quarantine site — the 'real'
  mechanism) and secondary/flavor (Dream Echo, Psychic/Munna-triggered,
  a temporary unstable partial view, earlygame teaser). Resolves a
  tension between two liked ideas without making napping the
  load-bearing explanation for a scientific quarantine dimension.

- Lost Mob Grinders and Lost Biomes unified as artifacts and casualties
  of the SAME historical corruption event — recovering a grinder and
  researching a quarantined biome become two entry points into one
  mystery rather than two unrelated 'ancient ruins' flavors.

8\. Additional Systems Locked

- World Affinity Threshold-Gated Machines: a non-consumptive check where
  machines require a minimum local World Affinity of a matching type to
  function, distinct from the Legendary Domain Authority gate. Applied
  to Cobblemon Trial Spawners: primary type is a hard gate, secondary
  type (for dual-type Pokemon) is a bonus tier rather than also required
  — explicitly NOT the same logic as an existing Grass+Fairy machine
  example where both types WERE required, because that example
  represented one unified concept and most dual-types don't.

- Trainer Resonance locked as the starter's ability — an ongoing,
  scaling ability rather than a one-time selection event. Three
  relationship tiers (Resonant/Attuned/Unattuned). Trainer Affinity and
  World Affinity confirmed as genuinely separate axes;
  catching/releasing is explicitly NOT the primary Trainer Affinity
  source (meaningful interaction is).

- Badges function as wearable Curios linking to the Resonance Heart
  system, never consumed, movable between Badge Box and active slot.

- The Prize Pool: a single shared master list of everything usable as a
  prize/reward/effect across every reward-granting system (quests,
  research, gym victories, Titan defeats), so no future system
  re-invents its own reward taxonomy. Seeded with ~20 concrete entries
  including Temporary Resonance Sight (a color-coded Affinity-aura
  vision buff, correctly cited to a real spell effect, Planar Sight,
  from Iron's Spells 'n Spellbooks).

- Sweet Resources: Combee/Ribombee/Vespiquen Affinity-infused
  honey/pollen/jelly production, a custom multiblock studied against
  Mystian Apiary as design reference only (not its proprietary
  code/assets).

- Empoleon Trident Resonance: a worked example (and named reusable
  pattern) tying a Pokemon's real design to genuine Minecraft mechanics
  — Loyalty/Channeling/Riptide as three distinct Resonance forms plus a
  rare Trident Mastery state requiring all three.

- Waystones/Tempad/Palkia fully resolved as a progressive two-tier
  unlock, not a permanent exemption from progression. A joint
  Palkia+Dialga 'Space Time' recognition event reuses the already-locked
  Titan escape/re-encounter pattern.

- Prismarite Crystal (Regions Unexplored's decorative rainbow crystal)
  reinterpreted as a natural Affinity reservoir with a five-stage
  extraction lifecycle (Shards/Dust/Blank Gem/Liquid Affinity/Pure
  Affinity depending on method).

- Titan battle transition mechanics: atomic boss-to-Pokemon
  transformation with no idle gap, a 6-spoke radial wheel for Pokemon
  selection (Tool Belt/Iron's Spells-style), reward tied specifically to
  the Pokemon-battle phase, loss causing retreat rather than death.

9\. Core Mod Skeleton Finalized

NeoForge 1.21.1 confirmed as the loader (a brief Fabric recommendation
was caught and reversed within the same conversation). Sinytra
Connector + Forgified Fabric API as the deliberate bridge for genuinely
valuable Fabric-only mods, native NeoForge always preferred first.

- Layered install order: NeoForge → Cobblemon + Kotlin for Forge →
  KubeJS + Rhino → FTB stack (Library/Teams/Quests/XMod Compat) +
  Architectury → JEI (chosen over EMI for its XMod Compat integration) +
  Jade + Patchouli + Curios → performance stack
  (ModernFix/FerriteCore/Embeddium/ImmediatelyFast/Entity Culling) →
  worldgen foundation (Lithostitched/TerraBlender/Regions Unexplored) →
  QoL → Create as the one large content mod treated as core, with
  Mekanism and Ars Nouveau deliberately deferred (Mekanism's own 1.21.1
  NeoForge build is labeled alpha by its author).

- cer: adopted as the single canonical namespace for all custom content,
  replacing two competing candidates (cobblemon_er, er) that arose
  separately without either being formally chosen.

- Enhanced Celestials verified real and current (44M+ downloads, active
  NeoForge 1.21.1 builds), filed as the intended data source for a ball
  Environmental Resonance Component.

- Pokebelt dropped in favor of reskinning a Vanilla Backport Bundle as a
  'Trainer's Belt' — same fantasy, zero new dependencies, since Pokebelt
  never resolved to a native NeoForge port.

- Vanilla Backport's bundled Chaos Cubed/Sulfur/Cinnabar content
  (confirmed NOT actually a vanilla backport, but bonus content in the
  same jar) logged as a separate, independently removable M.M.I. entry
  from the genuine vanilla-content half.

- Implementation Layer Principle proposed (not yet formally
  cross-referenced against the four existing F.R.M. principles):
  content/rules → datapack; new capability → mod; cross-mod glue →
  KubeJS; presentation-only → resource pack. Never drop to a lower layer
  merely because it's technically possible.
